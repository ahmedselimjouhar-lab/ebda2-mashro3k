# 🚀 ابدأ مشروعك | حاسبة استثمار رأس المال الذكية (ebda2-mashro3k)

أداة تفاعلية ذكية بتصميم **Apple Minimalist** لمساعدة المستثمرين ورواد الأعمال في مصر والوطن العربي على توظيف رأس المال بأعلى عائد ممكن، واستغلال الأصول المتاحة لديهم بذكاء، مع مقارنة فورية بين الأوعية الادخارية والمشاريع التشغيلية.

---

## ✨ أهم مميزات المنصة

* **💱 تحديث لحظي لسعر الصرف:** ربط تلقائي بواجهة بيانات أسعار العملات لحساب الاستثمارات بالجنيه المصري (`EGP`) أو الدولار الأمريكي (`USD`) لحظياً.
* **🚗 استغلال الأصول المتاحة (Asset Optimization):** إعادة ترتيب الفرص الاستثمارية وحساب الوفر المالي تلقائياً بناءً على ما يمتلكه المستخدم (سيارة خاصة، سطح منزل، أرض فضاء، أو مخزن).
* **📊 تغطية شاملة لقنوات الاستثمار:**
  * **الأوعية المالية والعائد السلبي:** شهادات البنوك، صناديق الاستثمار النقدية والذهب، والبورصة المصرية (`EGX30`).
  * **مشاريع الأسطح والإنتاج الزراعي والداجني:** زراعة الدراجون فروت، إنتاج المشروم المحاري، زراعة الزعفران والأعشاب العطرية، وتربية الدواجن والبط المسكوفي والديك الرومي.
  * **المشاريع التجارية والخدمية:** المتاجر الإلكترونية (`Micro-Brands`)، أركان القهوة المختصة والماتشا، كافيهات السيارات المتنقلة، وخطوط التوزيع المباشر.
  * **مساهمات المشاريع القائمة:** قسم خاص للشراكة في المشاريع القائمة التي تحقق عوائد فعلية (لرؤوس الأموال من 400,000 ج.م فأكثر).
* **🗺️ خريطة زمنية وتقسيم الميزانية:** خطة عمل مبسطة على إطار زمني متسلسل مع توزيع السيولة بقاعدة التحوط (80% تشغيل / 20% صندوق أمان).
* **📦 دليل المصادر والجهات المعتمدة:** ربط كل فرصة بقائمة منافذ الجملة، الموزعين، والجهات الرسمية المناسبة لشريحة رأس المال.
